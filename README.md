# 窗合 · PaneFlow

一个独立的 macOS 菜单栏窗口工具。自定义布局、窗口磁吸、共享边界联动缩放，以及分区放置与交换。它通过公开的 AppKit 和辅助功能接口控制普通窗口。

![PaneFlow 磁吸与联动布局示意：窗口贴边、左一右二共享边界缩放，以及 Option 拖动放入分区](docs/assets/layout-and-snap.svg)

示意图使用虚构窗口，不是系统截图。PaneFlow 只排列你选择的窗口，不接管全局自动平铺。

目前处于开发阶段，应用使用本地签名；尚未提供公证的安装包。

已有本地 DMG 安装包时，双击打开，将 `PaneFlow.app` 拖到 `Applications`，再从“应用程序”启动。辅助功能权限按应用中的提示开启。

## 开始使用

需要 macOS 14+、Swift 6.0+ 的 Xcode 或 Command Line Tools。从源码构建：

```sh
/bin/zsh scripts/build-app.sh
open build/PaneFlow.app
```

1. 打开 `build/PaneFlow.app`。设置窗口会显示，图标保留在菜单栏；关闭设置后应用继续运行，再次双击应用会重新显示设置，最小化后也会恢复。
2. 查看设置中的辅助功能状态；若显示“未允许”，点击“开启辅助功能”，在“系统设置 → 隐私与安全性 → 辅助功能”中允许“PaneFlow”。已授权时显示“已允许”。
3. 从菜单栏打开“练习窗口”，先用三个专用窗口体验。
4. 从菜单栏选择“打开布局面板”。也可以选中一个窗口后按 `Control–Option–Space`，或按住 Option 悬停绿按钮。
5. 选择布局，点击一个区域放置当前窗口；已有窗口时交换位置。也可以勾选多个窗口，点击“排列并联动”，按勾选顺序填入分区。

排列列表按应用分组，展开后勾选具体窗口；组标题显示窗口总数和已选数量，折叠保留勾选。左侧蓝色选择框内显示 1、2、3 等序号，按勾选先后放入对应区域；取消后恢复空框，重选排到最后。刷新和折叠分组保留顺序，关闭窗口后剩余序号自动连续。快速放置单个窗口时，先选中那个窗口，再按 `Control–Option–Space` 并点击目标分区；也可按住 Option 拖动标题栏到高亮分区。

也可以直接把列表中的窗口标题拖到上方分区，放置指定窗口；把预览里已占用的窗口拖到另一个分区，可交换位置，支持跨显示器。目标分区会高亮，留白不接受放置。拖放后面板保持打开，便于连续调整；点击分区放置或批量排列成功后仍自动收起。关闭面板不会撤销已完成的调整，误操作可点“撤销”。

已有窗口管理器使用相同快捷键时，菜单栏入口仍可用。普通绿按钮点击继续由 macOS 处理。

布局面板使用系统磨砂材质，顶部只显示当前应用图标和窗口标题。按住 Option 悬停绿按钮时显示小箭头；快捷键打开时采用无箭头浮层，放在标题栏下方，随屏幕空间选择上方或下方展开。顶部的图标、标题和留白可直接按住拖动。放置或排列成功后自动收起；点击外部、按 Esc 或再次按 `Control–Option–Space` 也会收起，窗口联动仍然保留。布局菜单展开时 Esc 先关闭菜单；调整失败时面板保留并显示原因。“管理…”会收起面板并打开统一的布局管理页。也可从应用菜单选择“设置…”或按 `Command–,` 打开设置。

### 集中管理多套布局

从菜单栏选择“布局管理…”，或点击布局面板中的“管理…”、设置中的“布局管理…”，都会进入同一个窗口。

左侧选择布局，右侧编辑名称和分隔线。选中自己的已有布局后点“保存修改”，会更新原布局。需要另一套方案时，使用左侧“新建”或“复制”；内置布局通过“复制并编辑”创建自己的版本。删除只作用于选中的自定义配置，并会先显示确认。

切换左侧列表会保留各布局的未保存修改；关闭管理页或退出应用时可全部保存、继续编辑或放弃修改。保存失败会显示原因并保留草稿。保存布局不会移动当前窗口，也不会改动已经建立的联动组；重新排列窗口后才采用新的布局形状。

### 横竖分隔线与留白

选中一块区域，点“加竖线”或“加横线”继续划分。拖线按整个编辑画布的 1% 网格微调；点中线后会显示位置百分比和微调箭头，箭头每次调整 1%。竖线位置从左侧计算，横线从顶部计算；也可以直接输入小数位置。移动一条线时，其他线的位置保持不变，分隔线不能互相越过。

选中不想放窗口的区域，点“留白”。留白以虚线表示，自动排列、点击放置和拖入分区都会跳过它。所有区域都放窗口就是铺满；留出几块空白即可让一个或多个窗口只占屏幕的一部分。每块屏幕最多包含 16 个区域（含留白）。

“2/3 居中”预设就是两条竖线加左右留白，中间区域放一个窗口。零间距时宽度为可用区域的 2/3；非零间距和屏幕留边也会参与实际位置计算。两窗口留白可用同样方式划出外围空白，只保留中间两个窗口区域；相邻窗口仍支持联动。

### 跨显示器布局

在布局管理页选择自己的布局，展开“显示器”菜单，勾选要使用的屏幕。所有已选屏幕会在同一画布中一起显示，保留系统中的相对位置和横竖方向。直接点击任意屏幕里的区域或分隔线，即可添加横线、竖线、设置留白或按 1% 微调，然后保存。屏幕选择和各屏分区共同构成一套布局；例如横屏三个区域、竖屏两个区域，可以一次排列五个窗口。

编辑窗口默认加宽，并根据屏幕组合和当前显示器的可用空间调整尺寸；画布随操作区域缩放。也可以手动拖动窗口边缘放大。

布局面板会分别预览这些屏幕。勾选窗口后，按屏幕选择顺序逐个填入区域，窗口次序采用勾选序号，留白自动跳过。点击预览中的区域也能把当前窗口放到指定屏幕；按住 Option 跨屏拖动时，只在这套方案选中的屏幕上显示分区。每个区域属于单块屏幕，按各屏的可用空间与缩放计算。

整套排列、跨屏交换均可撤销；同屏相邻窗口继续联动。没有勾选的屏幕不会成为该方案的放置目标，未选中的窗口保持原位。某块指定屏幕未连接时，整套排列会提示连接或取消选择，不会自动改用其他屏幕。取消勾选后，在当前编辑会话中重新勾回可恢复该屏幕草稿。

选择“跟随当前窗口”可恢复原来的单屏使用方式，已有布局升级后继续采用这一方式。

### 从当前窗口读取布局

在自己的布局或新建布局中点击“读取窗口排列…”。列表按显示器列出当前桌面可读取的普通窗口，包含应用、窗口标题和大小；勾选要参与的窗口，右侧会同时显示它们在各屏的位置。点击“刷新”可重新读取窗口清单。

点击“生成布局”时会再次读取所选窗口的当前位置和大小，转换成可编辑的横竖分区和留白。这个过程只更新布局草稿，真实窗口保持原位，保存后才写入配置。窗口关闭、互相重叠、跨越屏幕边界，或无法用每屏最多 16 个分区表示时，会说明原因并保留原草稿。

读取的布局保留实际窗口间隙和屏幕留边，不叠加全局间距设置；需要改回全局值时，在“间距：已读取”菜单选择“跟随设置间距与留边”。读取时相近的窗口边缘允许 2 pt 的系统调整误差。配置只保存屏幕与区域形状，不保存所选窗口的身份或标题。

### 绿按钮入口

macOS 绿按钮原生菜单中的项目不支持在 PaneFlow 内修改。PaneFlow 的自定义布局位于独立面板：按住 `Option` 悬停绿按钮，或用 `Control–Option–Space` 打开；在“布局管理…”中统一编辑多套布局。普通悬停和点击仍使用系统行为。使用系统菜单排列窗口不会自动创建 PaneFlow 联动组。

## 四个模块

- 自定义布局：内置左右、上下、左宽右窄、一大两小。布局管理页支持选择已有布局直接修改、改名，复制或新建多套布局；可选择参与的显示器，分别编辑分区。每屏最多 16 个区域。
- 窗口磁吸：普通标题栏拖动时，对其他可见窗口贴边、对齐。吸入距离 14 pt，拉开超过 26 pt 解除；按住 Control 临时跳过。窗口磁吸不会创建关联组。
- 联动缩放：主动放入同一布局的窗口才关联。拖动窗口之间的灰色分隔条，或拖动窗口的共享边缘，邻窗一起调整。分隔条使用系统磨砂材质，悬停时显示把手与缩放光标，拖动时高亮。只在组内应用处于前台、窗口符合当前布局且共享边界未被遮挡时显示。设置和布局面板会显示关联状态及分隔条未显示的原因。拖出布局、单独改变外边缘会解除该窗口的关联。
- 分区与交换：按住 Option 拖动窗口标题栏，显示当前布局区域。松手放入空区域，或与占用窗口交换。跨组交换同时更新两组；从布局外拖入占用区域时，占用窗口移至拖入窗口原来的位置。

菜单栏提供撤销（最近 20 次成功操作）、暂停和退出。设置可独立开关磁吸、联动、分区和绿按钮入口，并调整间距与留边。新设置的窗口间距默认为 0 pt，窗口之间无缝排列。

“左边一个、右边两个”可选择“一大两小”，勾选三个窗口后点击“排列并联动”。左右共享边界有上下两个竖向分隔条，拖动任意一个都会同步调整左窗和右侧两窗；右侧还有一个横向分隔条，用于调整上下比例，左窗保持原样。想让左右各占一半，可在布局管理页中将最外层左右比例设为 50%。

保存布局只保存形状，不会关联已经手工摆好的窗口。窗口关联仅保留到应用退出；重启后需再次排列窗口建立联动。贴边磁吸独立生效，长窗口也可吸附到两扇短窗口的边缘。

## 辅助功能权限

构建产物使用本地 ad-hoc 签名，重新构建后 macOS 可能要求重新开启辅助功能权限。应用启动后会显示当前权限状态。

如果重新构建后，系统设置开关已开启，但当前应用仍提示无权限，先退出 PaneFlow。可用下面的系统命令清除 PaneFlow 的旧授权记录，再打开当前应用，点击“开启辅助功能”，开启新生成的 PaneFlow 条目。这会重置本应用的辅助功能授权。

```sh
tccutil reset Accessibility app.paneflow.window-manager
```

## 兼容性与本地数据

只处理当前桌面上公开了可移动、可缩放辅助功能接口的普通窗口。全屏、最小化、隐藏、对话框和不可调整窗口不参与。普通多显示器坐标、缩放、菜单栏和 Dock 的可用区域均参与布局计算；不包含显示器断连/重连恢复，也不接管全局自动平铺。

应用可能拒绝某个尺寸或延迟调整。拖动预览合并最新鼠标位置，已确认响应的窗口可在同一轮完成两个方向的调整；分隔条随预览移动，松手校验期间保持可见。延迟过大的应用仍在松手后完成最终校验；失败时尝试恢复拖动前的位置。恢复失败会解除相关窗口联动并明确提示。应用未暴露的尺寸下限不能预先保证，实际写入与回读结果决定能否应用。

Edge 和自带练习窗口调整期间会临时暂停其增强辅助功能模式，以减少逐次窗口写入的动画延迟，结束后回读确认恢复；VoiceOver 或切换控制启用时保留该模式。拖动中暂停管理会解除受影响窗口的旧关联，保留其当前位置。

布局形状和设置保存在 `~/Library/Application Support/PaneFlow/preferences.json`。活窗口身份与关联组仅保存在内存中；设置文件不保存窗口标题、内容、键盘输入或截图。鼠标监听只用于判断窗口拖动与修饰键，不记录输入。没有账号、网络、遥测或开机启动设置。

布局入口是绿按钮旁的独立面板。不会向其他应用注入代码，不更改系统原生菜单，不要求关闭 SIP。
